# 金句卡本地渲染管线（无需生图模型）

小绿书配图的主力是「金句卡 / 书单卡」——它们本质是**排版设计图，不是绘画**。用 PIL 本地渲染 PNG：零成本、秒出、无 AI 标注义务（发布页不用勾「内容由 AI 生成」，合规上比生图模型干净）。

生图模型（豆包/Gemini）只负责「场景氛围图」这类摄影感配图，每篇 0–1 张，见文末。

## 模板脚本

`tools/quote_card.py`，单文件无其他依赖（PIL + 系统中文字体）：

```bash
python quote_card.py --quote "金句内容" --source "——《书名》" --out 输出.png --theme cream
# 可选 --tag "底部小字"（默认「每天读一点 · 把书读薄」）
```

**依赖**：Python 3.x + Pillow；字体走 Windows 系统字体（华文楷体 `STKAITI.TTF` 做正文、微软雅黑做辅助信息）。迁移到 mac/Linux 时替换字体路径即可。

## 设计规格

| 项 | 值 |
|---|---|
| 画布 | 1242×1660（3:4，公众号小绿书推荐规格），PNG 约 80–90KB |
| 版式 | 顶部品牌字「鲸默读书」+ 分隔线 → 双线边框 → 引号包裹的正文 → 出处 → 底部菱形 + tag |
| 引号 | 成对装饰：opening 贴正文首行上方（左上），closing 挂末行右下，对角呼应 |
| 配色 | 四主题：`cream`（治愈/认知默认）/ `sage`（清新）/ `night`（深夜独白）/ `ink`（国学·朱砂点缀） |

## 排版算法（踩坑后的正确做法）

1. **按标点切自然短句**（，。；！？、：为界），短句是断行的基本单位——直接按字宽断行会把「自我批判」拆成「自我批/判」
2. **字号自适应 = 保证最长的自然短句不超宽**：从 92px 往下试，取第一个能容纳最长短句的字号。而不是「行数不超高度」——后者会让长句拆词
3. **禁止行首标点**（。，」等）作为兜底规则
4. 短句同行装箱：相邻短句合并放得下就并作一行
5. 行数超高的兜底：再缩字号 + 逐字断行

## 场景图生图提示词模板（豆包/Gemini 通用）

> 竖版 3:4 构图，{场景}的{风格}摄影风格：{3–4 个具体物件}，{光线与色调}，画面上方留白，{氛围}，真实摄影质感，高清细节。画面中不出现任何文字，不出现书籍封面特写，不出现人物面部。

硬规则（已验证的教训）：**画面无文字**（中文渲染不可靠）、**无书封特写**（假书一眼假）、**无可识别人脸**、**竖版 3:4 留白**（给标题叠字留空间）。

示例（治愈线·深夜书桌）：

> 竖版 3:4 构图，深夜书房一角的温馨写实摄影风格：原木书桌一角，一盏暖黄色小台灯亮着，桌上一杯冒着热气的茶，旁边一副翻旧了的居家棉拖鞋，背景是虚化的书架剪影，窗外是深夜的深蓝色，整体色调暖棕与深蓝对比，光线柔和安静，画面上方留白，治愈系氛围，真实摄影质感，高清细节。画面中不出现任何文字，不出现书籍封面特写，不出现人物面部。

## 批量生产

多篇出图写个循环即可（每篇两张卡、不同 quote/source/theme 组合）。产物统一放 `素材库/金句卡/`，命名 `{篇号}-首图|内页-{书名}.png`。
