# 金句卡生产管线（Gemini AI 生图主力 + 本地渲染备用）

小绿书配图的主力是「金句卡 / 书单卡」——首图必为金句卡。两条产线：

| 产线 | 工具 | 优点 | 合规 |
|---|---|---|---|
| **AI 生图（主力，2026-10-10 定版）** | Gemini（实测优于豆包，无水印） | 质感有感染力、用户接受度高 | **必须**勾「内容由 AI 生成」 |
| 本地渲染（备用/应急） | PIL 脚本（下述） | 零成本、秒出、文字 100% 准确 | **不用**勾「内容由 AI 生成」 |

**取舍**：默认走 Gemini；AI 出图文字核对不过关或需快速批量时切本地渲染。AI 卡**文字必须逐字核对**（首张实测即漏字）。

## 模板脚本

`tools/quote_card.py`，单文件无其他依赖（PIL + 系统中文字体）：

```bash
python quote_card.py --quote "金句内容" --source "——《书名》" --out 输出.png --theme cream
# 可选 --tag "底部小字"（默认「每天读一点 · 把书读薄」）
```

**依赖**：Python 3.x + Pillow；字体走 Windows 系统字体（华文楷体 `STKAITI.TTF` 做正文、微软雅黑做辅助信息）。迁移到 mac/Linux 时替换字体路径即可。

## 设计规格

| 项 | 值 |
|---|---|
| 画布 | 1242×1660（3:4，公众号小绿书推荐规格），PNG 约 80–90KB |
| 品牌字 | **「鲸默阅读」**（统一用此名，勿用「鲸默读书/鲸默的思维」等旧误记）；slogan「每天读一点 · 把书读薄」 |
| 版式（v2 warm 默认） | 渐变底+暖光斑 → 圆角细框 → 品牌字+波浪线 → 引号包裹正文 → 出处 → **冒热气的茶杯插画** → tag |
| 引号 | 成对装饰：opening 贴正文首行上方（左上），closing 挂末行右下，对角呼应 |
| 配色 | `warm`（温馨治愈，v2 默认：奶油→暖杏渐变+焦糖橙）/ `cream` / `sage` / `night` / `ink` |

**v2 背景**：用户反馈旧版「单调无聊，这本书更适合温馨感」→ 重做为暖渐变+光斑+茶杯简笔画（PIL 手绘：圆角矩形杯身+椭圆杯口+arc 杯柄+正弦蒸汽线），治愈书单适配度显著提升。茶杯可换成其他小元素（如小蛤蟆）做差异化。

## 排版算法（踩坑后的正确做法）

1. **按标点切自然短句**（，。；！？、：为界），短句是断行的基本单位——直接按字宽断行会把「自我批判」拆成「自我批/判」
2. **字号自适应 = 保证最长的自然短句不超宽**：从 92px 往下试，取第一个能容纳最长短句的字号。而不是「行数不超高度」——后者会让长句拆词
3. **禁止行首标点**（。，」等）作为兜底规则
4. 短句同行装箱：相邻短句合并放得下就并作一行
5. 行数超高的兜底：再缩字号 + 逐字断行

## 场景图生图提示词模板（Gemini 主力，豆包备用）

> **实测结论（2026-10-10）**：同一提示词 Gemini 出图质量明显优于豆包且无水印，场景图主用 Gemini。生图卡文字同上须逐字核对。

**叙事法则（关键教训）**：只给「物件清单」（桌子+书架+拖鞋+咖啡）会得到「不明所以的静物堆砌」；给**主角+动作+情节**才有感染力——如绘本风蛤蟆穿毛衣在壁炉旁扶手椅上读书（用户评价「很完美」）。备选叙事：壁炉+摊开的书+垂下的毛毯+打盹的猫（「有人刚离开」的生活痕迹）。

> 温馨治愈系儿童绘本水彩插画，竖版 3:4。{主角：圆滚滚的蛤蟆穿米色针织毛衣}窝在{场景：壁炉旁的橙红色布艺扶手椅}里，{动作：膝上摊着一本打开的书，正低头安静阅读}。旁边{道具：小圆几上一杯冒热气的茶、一盏暖黄台灯}。{环境：壁炉柔和火光，窗台绿植，空气中漂浮细微暖色光斑}。整体色调奶油色与焦糖橙，笔触柔软，画面安静、治愈、有安全感。画面中不出现任何文字，不出现人脸，主角以侧面或四分之三角度呈现，不要直视镜头，保留呼吸感留白。

硬规则（已验证的教训）：**画面无文字**（中文渲染不可靠）、**无书封特写**（假书一眼假）、**无可识别人脸**、**竖版 3:4 留白**（给标题叠字留空间）。

**AI 金句卡提示词结构**（Gemini 实测可用，文字错漏高发须人工逐字核对）：比例 3:4（1242×1660）→ 背景渐变+四角柔焦光斑+碎金光点 → 细焦糖橙圆角边框 → 顶部品牌字+波浪线 → 大号楷体引文（**注明「必须逐字准确、不得有错别字」并给出完整引文**）→ 成对引号装饰 → 小号出处 → 底部茶杯简笔画+tag → 「除上述文字外不得出现任何其他文字」。

**核对清单（AI 卡上架前必过）**：① 引文逐字比对（实测首张即漏「有」字）② 出处书名作者名逐字 ③ 引号成对 ④ 无多余乱码文字 ⑤ 发布勾「内容由 AI 生成」。

## 题签区规格（2026-10-11 定版，全系列统一）

封面场景图顶部为「品牌字 + 书名」两行题签（#2《被讨厌的勇气》v3 验证成图）：

| 项 | 规格 |
|---|---|
| 位置 | 顶部居中；品牌字第一行，书名第二行正下方，行距紧凑 |
| 品牌字 | 「鲸默阅读」四字，**每张图尺寸严格一致**：总宽约占画面宽度 55%，深棕圆润可爱体 |
| 书名字号 | 同风格字体，字号约为品牌字的 60%（≈品牌字总宽的 70–80%）；**按书名长度自适应**：≤6 字用标准档，7–10 字再缩一号保证单行，>10 字允许分两行 |
| 底部 | 距底边 10–12% 是系统信息流标题遮罩区，**必须留白**，不画任何元素 |

封面提示词文字段模板（变量：书名）：

> 文字要求：画面顶部居中，第一行用深棕色圆润可爱的字体清晰工整地写四个字「鲸默阅读」，四字总宽约占画面宽度 55%；正下方第二行用同风格字体清晰工整地写书名「{书名}」，字号约为第一行的 60%，若书名超过六字则相应缩小以单行排完，两行笔画必须准确无误、排列整齐、间距适当。除这两行文字外，画面中不得出现任何其他文字，不出现人脸。画面下半部保持干净留白，不绘制任何文字或元素。
